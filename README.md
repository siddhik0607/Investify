# Investify — Goal-Based Investment Simulator 📈

Investify is a powerful, user-friendly financial planning tool designed to help you turn your dreams into actionable investment plans. Whether it's a new car, a dream home, or a luxury vacation, Investify calculates exactly how much you need to save and visualizes your wealth growth over time.

## 🚀 Live Demo
Check out the live website: [investify-pro.vercel.app](https://investify-pro.vercel.app/)

---

## ✨ Key Features

### 1. **Smart Goal Planning**
- **Customizable Goals**: Choose from preset categories (Car, Home, Travel) or create your own custom financial targets.
- **Dynamic Calculations**: Automatically calculates the required monthly SIP (Systematic Investment Plan) based on your target amount, duration, and expected returns.

### 2. **Secure Authentication System**
- **Encrypted Passwords**: Uses `bcryptjs` for industry-standard password hashing before storing in the database.
- **Direct Database Storage**: All user data is securely stored in a custom Supabase database, ensuring your privacy and data integrity.
- **Personalized Experience**: Once logged in, the platform greets you by name and tracks your specific financial journey.

### 3. **Interactive Visualizations**
- **Growth Charts**: Beautiful, interactive charts powered by `Recharts` to visualize how your money grows year by year.
- **Progress Tracking**: Real-time progress bars and milestone celebrations to keep you motivated.

### 4. **Financial Tools & Insights**
- **Affordability Score**: Evaluates if your chosen SIP amount is comfortable based on your monthly income.
- **Risk Profile Quiz**: Helps you understand your investment personality and recommends appropriate return expectations.
- **Scenario Simulator**: Test "what-if" scenarios—see what happens if you increase your SIP or extend your target date.

### 5. **Modern User Experience**
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Sleek UI**: Built with Tailwind CSS and Shadcn UI for a professional, "bank-grade" aesthetic.
- **Dark Mode Support**: Gentle on the eyes for late-night financial planning.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons, Shadcn UI
- **Backend/Database**: Supabase (PostgreSQL)
- **Security**: Bcryptjs (Password Hashing)
- **Deployment**: Vercel
- **State Management**: React Query (TanStack Query)

---

## 🛡️ Security & Privacy

Investify prioritizes your security. We never store plain-text passwords. All credentials are encrypted using one-way cryptographic hashing before reaching our database, ensuring that even in the database, your actual password remains invisible.
